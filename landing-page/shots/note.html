ingestor

A production eval harness you can copy

Studio Hours · Tactical · 2d ago · Gemini

Speaker: Maya Chen, staff engineer, Studio Hours

Goal / Outcome

A single-repo eval harness that scores agent traces against a gold set of 40 tasks, runnable in CI on every PR.

Resource stack

  • pytest + a JSONL gold file
  • OpenTelemetry traces, not screenshots
  • Gemini Flash for the judge; Pro only on fail

Tactical tutorial (SOP)

  1. Freeze 40 tasks as gold.jsonl (input, expected tool calls, expected final).
  2. Run the agent with tracing on. Write one span per tool call.
  3. Diff spans against gold. Fail the PR on missing or extra tools.
  4. Only then call a judge model on the final answer.

Heuristics & pitfalls

  • Do not let the judge invent extra criteria.
  • If the gold set moves weekly, you are measuring prompt churn, not quality.
